## Worth studying

- [Nemotron-Labs-Diffusion: a tri-mode AR + diffusion + self-speculation LM](https://arxiv.org/abs/2607.05722) — NVIDIA (26 authors): the clearest current case that AR and diffusion decoding are complementary rather than rival paradigms. One architecture, trained with a JOINT AR-diffusion objective, switches among AR (left-to-right priors), diffusion (better lookahead planning) and self-speculation to sustain throughput across concurrency levels — and in self-speculation mode diffusion beats multi-token-prediction on acceptance rate. Shipped OPEN at 3B/8B/14B (base/instruct/VL): the 8B decodes 6× more tokens/forward than Qwen3-8B at comparable accuracy → 4× higher throughput on SGLang/GB200. Study it as the reference for unifying AR and diffusion in one model (mode-switch by deployment regime) and as the 4th independent / 2nd major-lab open diffusion-capable base; caveat: throughput is vendor-reported and first-class native diffusion serving is not yet confirmed in an engine release.
- [OmniOpt: Taxonomy, Geometry, and Benchmarking of Modern Optimizers](https://arxiv.org/abs/2607.04033) — 12 authors (top HF daily paper 07-07, 67 up): a unified survey + benchmark "cookbook" for the 100+ modern optimizers, built to make optimizer selection — now a system-level design decision constrained by compute, memory, tuning budget and task diversity — tractable. It treats every optimizer update as a structured transformation through a five-stage meta-pipeline, exposing the shared geometry, then benchmarks under matched budgets. Read it before picking an optimizer for a large training run.
- [Bridging the Gap Between Latent and Explicit Reasoning with Looped Transformers](https://arxiv.org/abs/2606.31779) — Ying Fan, Anej Svete, Kangwook Lee: the clearest current answer to "why has latent chain-of-thought underperformed, and can it be fixed?" Latent CoT is more efficient but LOSES to explicit CoT beyond ~1B params and the gap WIDENS with scale; this paper argues looped / recurrent-depth Transformers are the natural substrate and gives a simple recipe (a looped padded Transformer processing K latent blocks) that closes the gap. The scaling-honest reference for the looped/latent-reasoning line.
- [AI-Infra-Guard: Multi-Layer Agent Red Teaming](https://arxiv.org/abs/2606.31227) — Yong Yang et al. (10 authors): a practical, open-source blueprint for the agent-security stack. Its load-bearing observation is that an agent's attack surface is STRATIFIED — infrastructure, protocol/tool (MCP servers, agent-skill packages), behavior, model — and no single detection paradigm covers all layers, so it matches a technique to each: rule-matching over 75+ components / 1,400+ vuln rules, LLM-driven MCP/skill auditing, multi-turn black-box red teaming, and a 26+-operator jailbreak harness. Study it as the tool-shaped instance of the "security moves into the architecture" thesis and a checklist of what each layer needs tested.
- [SkillOpt: Agent skills as trainable parameters](https://www.microsoft.com/en-us/research/blog/skillopt-agent-skills-as-trainable-parameters/) — Microsoft Research: the cleanest current statement of "make the skill file itself trainable." SkillOpt treats the skill file as a trainable parameter OUTSIDE a frozen model and optimizes it as a controlled process (bounded edits, validation gating, rejected-edit feedback, slow/meta updates). Best-or-tied-best in all 52 eval cells with NO weight updates, and skills transfer across model scales and harnesses — the weight-free counterpart to the compile-behavior-into-adapters line.
- [Memora: A Harmonic Memory Representation](https://www.microsoft.com/en-us/research/blog/memora-a-harmonic-memory-representation-balancing-abstraction-and-specificity/) — Microsoft Research: a clean design for agent long-term memory that decouples WHAT is stored (rich content) from HOW it is retrieved (lightweight abstractions + cue anchors). New SOTA on LoCoMo and LongMemEval, beating Mem0, RAG and full-context inference while using up to 98% FEWER context tokens — read it before building any long-horizon agent memory layer.
- [PrismML Ternary Bonsai (true 1.58-bit LLMs at 8B/4B/1.7B)](https://prismml.com/news/ternary-bonsai) — a commercial, independent (Caltech-origin) lab shipping a ternary-throughout LLM family: {-1,0,+1} weights in EVERY layer (embeddings, attention, MLPs, LM head), ~9× smaller memory than 16-bit. The clearest current existence proof of true 1.58-bit models ABOVE the ~2.4B research ceiling; caveat: benchmarks vendor-claimed, weights vendor-hosted (download availability unverified).
- [Program-as-Weights (PAW): compiling fuzzy functions into local adapters](https://arxiv.org/abs/2607.02512) — Wentao Zhang, …, Stuart Shieber (Harvard-line): the cleanest instance of the parametric-injection axis. PAW compiles a "fuzzy function" FROM a natural-language spec INTO a compact locally-executable adapter: a 4B compiler (trained on the released 10M-example FuzzyBench) emits a PEFT adapter for a frozen lightweight model. Study it as the "put behavior in weights, not the prompt" alternative to RAG/harness-context, and for the FuzzyBench + compiler recipe as a reusable pattern.
- [Ponytail (Claude Code skill: agents that write less code)](https://github.com/DietrichGebert/ponytail) — DietrichGebert; a practical daily-driver skill that steers coding agents toward a "lazy senior dev" discipline (YAGNI, stdlib before custom, native features before deps, one line before fifty), backed by a REPRODUCIBLE promptfoo benchmark on real headless Claude Code sessions: −54% LOC mean (up to −94%), −22% tokens, −20% cost, 100% safe. Study it for the token/cost lever AND as a rare example of a community skill measuring itself honestly.
- [TRIAGE: Role-Typed Credit Assignment for Agentic RL](https://arxiv.org/abs/2606.32017) — Yuanda Xu et al. (8 authors): the cleanest statement of the agentic-RL-credit problem. Standard GRPO spreads the final verifier outcome as a UNIFORM advantage over every action token; TRIAGE assigns role-typed credit to environment-facing action CLASSES instead. The current front of "outcome rewards are too sparse for long-horizon agents — assign credit at a finer grain" (with QVal, ECHO, and the Verification-Horizon diagnosis).
- [Senior SWE-Bench (Snorkel AI)](https://senior-swe-bench.snorkel.ai) — a deployment-grounded coding-agent benchmark built on "we treat agents like senior engineers, so why evaluate them like junior ones?" Feature tasks use under-specified instructions (a validation agent writes adaptive behavioral tests); bug tasks come from real PRs needing runtime investigation; scoring rewards "tasteful" solves against unstated codebase practices. Study it before trusting SWE-bench-style leaderboards for agent readiness.
- [DOPD: Dual On-policy Distillation](https://arxiv.org/abs/2606.30626) — Yu, Li, …, Yue, Yan, Wang (16 authors): OPD trains a student on its OWN sampled trajectories under dense token-level teacher signals. DOPD's contribution is a warning about the obvious "give more information" lever: infusing privileged information induces a *privilege illusion* — the student conflates the transferable capability gap with an information-asymmetry gap it can only mimic. Study it (with OPID and AsyncOPD) as the current state of on-policy distillation as post-training, and for the privilege-illusion failure mode as a design constraint.
